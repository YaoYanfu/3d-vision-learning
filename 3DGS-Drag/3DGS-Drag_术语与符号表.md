# 3DGS-Drag 中英术语与数学符号表

本表用于配合《3DGS-Drag: Dragging Gaussians for Intuitive Point-Based 3D Editing》阅读。中文名称与已有全文译文保持一致；“本文中的含义”是便于理解的简要说明，不是逐字翻译。章节和公式编号均对应原论文。

相关文件：[中文全文译文](D:/papers/3DGSdrag/3DGS-Drag_中文全译.md)；[原论文 PDF](<D:/papers/3DGSdrag/Dong和Wang - 2026 - 3DGS-Drag Dragging Gaussians for Intuitive Point-Based 3D Editing.pdf>)。

## 1 核心方法术语

| 英文术语 | 中文译法 | 本文中的含义 | 位置 |
| --- | --- | --- | --- |
| Point-based 3D editing | 基于点的三维编辑 | 用少量控制点及对应目标点表达编辑意图。 | §3.2 |
| Drag editing / Drag manipulation | 拖动编辑／拖动操作 | 指定某个三维部位应从当前位置移向何处，并据此改变场景。 | §3.2 |
| Handle point | 控制点 | 用户选定的三维拖动起点；附近一组高斯基元与该点关联。图中通常用圆形标示。 | §3.2–3.3 |
| Target point | 目标点 | 与控制点对应的期望三维位置。图中通常用三角形标示。 | §3.2–3.3 |
| Deformation guidance | 变形引导 | 先对高斯基元作粗略变形，使不同视角的渲染图具有共同的三维几何依据。 | §3.3 |
| Diffusion guidance | 扩散引导 | 利用扩散模型修复粗变形渲染图，再以修复后的图像监督三维高斯基元的优化。 | §3.4 |
| Drag deformation | 拖动变形 | 从稀疏控制点的位移和估计旋转出发，通过邻近点插值计算高斯基元的变形。 | §3.3 |
| Copy-and-paste | 复制粘贴 | 放入变形后的高斯基元副本，同时保留原基元并降低其不透明度，为后续保留、移除或扩展内容留下空间。 | §3.3 |
| Local editing mask | 局部编辑掩码 | 标记允许编辑的范围；本文同时使用作用于高斯基元的三维掩码和作用于图像的二维掩码。 | §3.3 |
| Mask dilation | 掩码膨胀 | 扩大二维掩码覆盖范围，使编辑能够调整邻近区域的上下文。 | §3.3 |
| Image2Image view correction | 图像到图像视图修正 | 对变形后的渲染图加噪，再经扩散模型去噪，纠正不合理内容和伪影。 | §3.4 |
| Iterative dataset editing | 迭代式数据集编辑 | 反复编辑用于训练三维表示的图像数据集；本文比较的既有策略每次只更新一帧。 | §3.4、附录B.2 |
| Annealed dataset editing | 退火式数据集编辑 | 对数据集进行有限次更新，每次更新所有视角，并逐渐降低图像到图像修正强度。 | §3.4，式（5） |
| Progressive editing | 渐进式编辑 | 将一次大幅拖动分为多个小阶段，逐步到达目标。 | §3.5 |
| Multi-step editing scheduler | 多步编辑调度器 | 为各个拖动阶段安排中间目标，并衔接控制点重定位等操作。 | §3.5，图2 |
| Handle point relocation | 控制点重定位 | 每个拖动阶段优化结束后，根据关联高斯基元的平均位置变化更新控制点位置。 | §3.5 |
| History-aware diffusion fine-tuning | 利用历史信息的扩散微调 | 用包含原始图像和历次编辑结果的图像缓冲区继续微调扩散模型，使其适应逐渐变化的场景。 | §3.5 |
| Image buffer | 图像缓冲区 | 保存用于扩散模型微调的图像；最初只有原始图像，随后加入新编辑结果。 | §3.5 |

## 2 三维表示、生成与编辑效果

| 英文术语 | 中文译法 | 本文中的含义 | 位置 |
| --- | --- | --- | --- |
| 3D Gaussian Splatting / 3DGS | 三维高斯泼溅 | 用一组三维高斯基元表示和渲染场景；是本文被编辑的三维表示。 | §3.1 |
| Gaussian / Gaussians | 高斯基元 | 场景中的表示单元，具有中心、尺度、旋转、不透明度和颜色特征。 | §3.1 |
| Explicit representation | 显式表示 | 高斯基元的位置等参数直接可访问，使粗变形操作能够直接作用于这些参数。 | §3.3 |
| Opacity | 不透明度 | 高斯基元参与成像时的不透明程度；复制粘贴操作中会降低原基元的不透明度。 | §3.1、§3.3 |
| Rotation quaternion | 旋转四元数 | 用四个分量表示三维朝向；本文分别计算控制点的旋转变化和高斯基元的新旋转。 | §3.1、§3.3、附录D |
| Densification | 致密化 | 三维高斯训练中增加基元、细化表示的过程；新基元继承相关掩码或关联信息。 | §3.3、§3.5 |
| Multi-view consistency / View consistency | 多视角一致性／视角一致性 | 不同视角下的编辑能够相互对应，共同描述同一个修改后的三维场景。 | §3.4，图3 |
| Geometry prior / Motion prior | 几何先验／运动先验 | 在编辑前用于约束结构或运动的知识，例如控制笼、物理假设或从动态场景学习的运动信息。 | §2.3 |
| Fine-tuning | 微调 | 在已有模型基础上继续训练，使其适应当前场景；本文用于扩散模型。 | §3.4–3.5 |
| LoRA / Low-rank adaptation | 低秩适配 | 本文用于微调扩散模型的适配方法；其作用是降低场景修复中的不一致性。 | §3.4、§4.1 |
| Inverse-free | 无需反演 | 本文的图像修正不需要先执行潜变量拖动方法所依赖的图像反演过程。仍然需要加噪、去噪。 | §3.4 |
| Image2Image strength | 图像到图像强度 | 控制图像修正幅度的参数；本文逐次减小该强度，使修正从较粗变化转向细节。 | §3.4，式（5） |
| Artifact | 伪影 | 编辑或优化产生的不合理视觉结构，例如漂浮碎片、破损区域和异常纹理。 | §3.4、§4.2 |
| Inpainting | 修补／补全 | 补充物体移开后显露区域等位置的内容，例如补回足球原位置的背景纹理。 | §4.2 |
| Content extension | 内容扩展 | 增长或扩展原有内容，例如延长袖子或让植物更高、更宽。 | 摘要、§4.2 |
| Unseen side | 未见侧面 | 原始视角未观测到的物体表面，例如背面；缺乏对应高斯基元时可能生成失败。 | 附录C.1 |

## 3 损失与评估术语

| 英文术语或缩写 | 中文译法 | 本文中的作用与阅读要点 | 位置 |
| --- | --- | --- | --- |
| Ground truth | 真值／参考目标 | 在式（6）中，编辑区用扩散编辑后的图像作监督，背景用原始图像作监督。编辑区目标是生成结果，并非真实拍摄的编辑后场景。 | §3.4 |
| L1 loss | L1 损失／绝对误差损失 | 与原图比较，用于约束非编辑区域。 | §3.4，式（6） |
| SSIM / Structural similarity | 结构相似性 | 式（6）采用相应损失约束非编辑区域；附录表1报告 SSIM 指标，数值越大越好。 | §3.4、附录B.3 |
| LPIPS | 感知距离 | 利用深度特征衡量图像的感知差异；式（6）用它修正编辑区域，附录表1也将其作为指标，数值越小越好。 | §3.4、附录B.3 |
| PSNR / Peak signal-to-noise ratio | 峰值信噪比 | 附录表1中衡量图像保留程度的指标，数值越大越好；该表仅评估未编辑像素。 | 附录B.3 |
| Ablation study | 消融研究 | 去除组件或改变策略，考察其作用；本文包括局部掩码、拖动步数和数据集更新策略。 | §4.2、附录B.2–B.3 |
| User preference | 用户偏好 | 参与者在不同方法结果之间的选择；正文为19人研究，附录扩大到99人。 | §4.3、附录B.4 |
| Editing effectiveness / Rendering quality | 编辑有效性／渲染质量 | 本文 GPT 评估的两个维度：是否正确完成编辑，以及渲染图像的视觉质量。 | §4.3，图8 |

## 5 数学符号速查

### 5.1 高斯参数

| 符号 | 含义 | 维度或说明 |
| --- | --- | --- |
| $\Gamma$ | 全体高斯基元的参数集 | 场景的三维高斯表示。 |
| $\Gamma^i$ | 第 $i$ 个高斯基元的参数 | $\{\mu^i,s^i,q^i,\alpha^i,c^i\}$。 |
| $\mu^i$ | 第 $i$ 个高斯基元的中心 | 三维位置，$\mathbb R^3$。 |
| $s^i$ | 高斯基元的尺度参数 | 三维向量，$\mathbb R^3$。 |
| $q^i$ | 高斯基元的旋转四元数 | 四维表示，$\mathbb R^4$。 |
| $\alpha^i$ | 高斯基元的不透明度 | 标量。 |
| $c^i$ | 高斯基元的颜色特征 | $\mathbb R^d$；$d$ 是颜色特征的维度／自由度。 |
| $\mu_d^i,q_d^i$ | 变形后的中心和旋转 | 下标 $d$ 对应 deformed；见式（3）、（4）。 |

### 5.2 控制点、邻域与变形

| 符号 | 含义 | 阅读要点 |
| --- | --- | --- |
| $n$ | 控制点数量 | 每个控制点对应一个目标点。 |
| $p_h,p_t$ | 控制点集合、目标点集合 | 均包含 $n$ 个三维坐标；原文写作 $p_h^{n\times3},p_t^{n\times3}$。 |
| $p_h^i,p_t^i$ | 第 $i$ 对控制点与目标点 | 下标 $h$ 对应 handle，$t$ 对应 target。 |
| $\Delta p_h^i$ | 第 $i$ 个控制点的位移 | $p_t^i-p_h^i$。 |
| $\tau$ | 关联高斯基元的距离阈值 | 决定控制点附近哪些基元被分配给它。 |
| $P_h^i$ | 与第 $i$ 个控制点关联的高斯基元集合 | 大写 $P$ 表示集合，小写 $p$ 表示点。 |
| $P_h$ | 所有关联高斯基元的并集 | $\bigcup_{i=1}^{n}P_h^i$。 |
| $K$ | 邻近控制点的选取数量 | 论文设 $K=2$；只有一个控制点时不施加旋转变化。 |
| $N_h^i$ | 控制点 $i$ 的邻近控制点索引集合 | 用于估计该控制点的旋转变化。 |
| $N_i$ | 高斯基元 $i$ 的邻近控制点索引集合 | 用于插值该基元的变形。 |
| $w_h^{ik}$ | 控制点之间的权重 | 由控制点 $p_h^i$ 与邻近控制点 $p_h^k$ 的距离计算；式（1）。 |
| $w^{ik}$ | 高斯基元对邻近控制点的权重 | 由高斯中心 $\mu^i$ 与控制点 $p_h^k$ 的距离计算；式（2）。 |
| $\Delta q_h^{ik}$ | 由第 $i,k$ 对控制点及目标点关系估计的旋转四元数 | 其构造见附录D。 |
| $\Delta q_h^i$ | 第 $i$ 个控制点的估计旋转变化 | 将邻近点提供的旋转四元数加权组合。 |

### 5.3 图像、掩码与损失

| 符号 | 含义 | 阅读要点 |
| --- | --- | --- |
| $M$ | 三维局部编辑掩码 | 标记哪些高斯基元可以修改。 |
| $m^v$ | 第 $v$ 个视角的二维编辑掩码 | 由高斯掩码渲染、阈值化并膨胀得到；覆盖原位置和目标位置。 |
| $v,V$ | 视角索引、参与损失求和的视角总数 | 式（6）对视角求和；实验默认选择50个视角。 |
| $I_r^v$ | 第 $v$ 个视角的当前高斯渲染图 | 下标 $r$ 对应 rendered。 |
| $I_e^v$ | 第 $v$ 个视角的编辑后图像 | 下标 $e$ 对应 edited；用作编辑区域的监督。 |
| $I_o^v$ | 第 $v$ 个视角的原始图像 | 下标 $o$ 对应 original；用作背景监督。 |
| $\mathcal L$ | 训练高斯基元的总损失 | 由非编辑区域的保留约束和编辑区域的修正约束组成。 |
| $\mathcal L_1,\mathcal L_{\mathrm{ssim}},\mathcal L_{\mathrm{lpips}}$ | L1、SSIM与LPIPS损失 | 前两项用于非编辑区域，后一项用于编辑区域；式（6）。 |
| $\lambda_1,\lambda_{\mathrm{ssim}},\lambda_{\mathrm{lpips}}$ | 三项损失的权重 | 实验分别设为8、2、1。 |

### 5.4 调度、步骤与附录符号

| 符号 | 含义 | 阅读要点 |
| --- | --- | --- |
| $T$ | 一次完整拖动被划分的阶段总数 | 外层多步拖动的步数；式（7）。 |
| $u$ | 当前拖动阶段的编号 | $u=1,\ldots,T$。 |
| $p'_t(u)$ | 第 $u$ 阶段的中间目标点 | $p_h+\frac{u}{T}(p_t-p_h)$。 |
| $p'_h(u)$ | 第 $u$ 阶段所使用的当前控制点 | 与阶段间的控制点重定位有关；图2。 |
| $A$ | 单步编辑内数据集更新的总次数 | 内层退火式数据集编辑的更新次数。 |
| $a$ | 当前数据集更新的编号 | $a=1,\ldots,A$。 |
| $S(a)$ | 第 $a$ 次更新的图像到图像强度 | 随更新逐渐降低；式（5）。 |
| $S_{\mathrm{init}},S_{\mathrm{final}}$ | 退火调度的初始与终止强度参数 | 按原文式（5）使用；与高斯尺度 $s^i$ 无关。 |
| $v_h^{ik},v_t^{ik}$ | 控制点连线和目标点连线的单位方向向量 | 描述点对在编辑前后的方向；式（8）。 |
| $r$ | 两个单位方向向量的叉积 | 三维向量，分量为 $r_x,r_y,r_z$；式（9）。 |
| $s$（附录D） | 两个单位方向向量的点积 | 标量；这里不是高斯基元的尺度参数。 |

常用运算符：$\otimes$ 表示四元数乘法；$\odot$ 表示逐元素乘法，式（6）中用于掩码加权；$\times$ 在式（9）中表示向量叉积，$\cdot$ 表示点积；$\|\cdot\|_2$ 表示欧氏范数；$\cup$ 表示集合并集。

## 6 最容易混淆的区别

| 容易混淆的概念 | 准确区分 |
| --- | --- |
| 控制点与高斯基元 | 控制点表达用户的操作意图；高斯基元构成实际场景表示。一个控制点关联一组高斯基元，两者不要求一一对应。 |
| 变形引导与扩散引导 | 前者提供粗略的三维空间变化；后者修复二维内容，再通过图像监督改善三维结果。 |
| 三维掩码 $M$ 与二维掩码 $m^v$ | 前者约束哪些高斯基元可以更新；后者区分每个视角中的编辑区和非编辑区，以安排不同监督目标。 |
| 拖动阶段、数据集更新、训练迭代、扩散时间步 | $T/u$ 管拖动分段；$A/a$ 管一个阶段内的数据集更新；训练迭代更新模型参数；扩散时间步属于加噪／去噪过程。它们不是同一种“步”。 |
| 3DGS优化与扩散微调 | 3DGS优化更新场景表示，使渲染匹配监督图像；扩散微调通过LoRA适配图像修复模型。 |
| 无需反演与无需扩散过程 | “无需反演”省去的是反演环节；本文仍然对渲染图加噪并通过扩散模型去噪。 |
| 多视角一致性与严格保证 | 论文通过共同的三维变形输入、场景微调和数据集更新改善一致性；并未给出对任意编辑都严格成立的数学保证。 |
| “不需要先验信息”与“完全没有先验” | 结合论文上下文，前者主要指不要求用户额外提供复杂几何或运动先验。方法仍然利用预训练扩散模型中的生成先验。 |
| 编辑区的“真值”与真实编辑后场景 | 式（6）中编辑区的监督来自生成图像。§4.3仍明确指出，三维编辑结果缺乏真实参考结果。 |

**符号阅读提醒：** 原文在不同上下文复用了 $i$、$s$、$v$ 等字母。式（1）后的控制点四元数加权表达式还使用了 $N_i$，与此前控制点邻域 $N_h^i$ 的写法不一致。本表按各自定义区分；若要复现算法，应进一步核对这些原文记号，不能仅凭字母外形判断含义。
